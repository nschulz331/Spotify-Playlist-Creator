# Spotify AI Playlist Creator

A full-stack, interactive web application built with Streamlit, the Google GenAI SDK, and Spotipy that lets users generate custom AI-curated playlists based on their personal preferences, music interests, and text-based prompts, then export them directly to their Spotify accounts.

## Features

* **Interactive UI:** Simple prompt-based input that allows users to describe their desired playlist, paired with real-time status tracking for AI recommendation generation and Spotify API operations.
* **AI-Powered Recommendations:** Integrates Google's `gemini-3.5-flash-lite` model with structured JSON generation to analyze user prompts and return relevant, unique song and artist recommendations.
* **Structured JSON Processing:** Uses Gemini-generated JSON data to organize recommended tracks and artists into a consistent format for accurate processing and Spotify integration.
* **Precise Track Matching:** Advanced Spotify search query formatting (`track:X artist:Y`) through `Spotipy` to improve track accuracy, prevent duplicates, and ensure recommendations match the intended songs and artists.
* **Automatic Playlist Creation:** Generates direct Spotify playlist links after successful creation, allowing users to immediately access their newly generated playlists.

## Tech Stack

* **Frontend/UI:** Streamlit
* **AI Integration:** Google GenAI SDK (`google-genai`)
* **Spotify API Integration:** Spotipy (`spotipy`)
* **Data Processing:** Structured JSON generated by Google Gemini
* **Environment:** Python 3, GitHub Codespaces
